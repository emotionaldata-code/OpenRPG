# Repository-local upstream skills

Installed with the Codex skill installer's explicit `--dest` option, scoped to this repository only.

- Colyseus: https://github.com/colyseus/skill (main), installed as `colyseus/`, with its references and MIT license.
- Phaser: https://github.com/phaserjs/phaser (master), the `skills/` directories for setup, scenes, input, sprites, animations, graphics, cameras, tilemaps, loading, and scaling. Bundled reference directories are preserved where provided upstream. Phaser is MIT licensed; see `PHASER-LICENSE.txt`.

Installation date: 2026-09-26. The skills are available to agents on subsequent turns. Global agent skills and configuration were not modified.
